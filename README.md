# Jignova Technologies Website

Static website (HTML, CSS, JavaScript) for **Jignova Technologies (OPC) Pvt Ltd**.

## Structure

```
.
├── index.html
├── css/
│   └── style.css
├── js/
│   └── script.js
├── assets/
│   └── logo.png
└── .nojekyll
```

## Publish with GitHub Pages

1. Create a new repository on GitHub (e.g. `jignova-website`).
2. Upload all files and folders in this project to the repository root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then **Save**.
5. After a minute, the site is live at `https://<your-username>.github.io/<repo-name>/`.

## Run locally

Open `index.html` in a browser.
